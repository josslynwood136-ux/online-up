# 美乐地（Melody）

一款仿手机桌面的移动端网页应用（PWA），核心是可与角色聊天的 AI 伴侣。

## 产品简介

**美乐地**是一款创新的AI伴侣应用，模拟手机桌面界面，提供沉浸式的交互体验。安装到桌面时显示名为"小手机"。

## 核心功能

### 🎭 AI 聊天伴侣
- 智能对话系统，支持多语言
- 流式实时分条技术，边生成边弹出气泡
- 角色主动发动态功能
- 时间感知系统，让角色体会等待的心情
- 自动记忆功能，记录重要信息

### 📱 桌面应用矩阵
- **打卡** - 日常签到系统
- **IG** - Instagram风格社交平台
- **音乐** - 音乐播放器
- **相册** - 照片管理
- **恋爱日记** - 情感记录
- **自习室** - 学习空间
- **直播间** - 实时直播
- **养多肉** - 虚拟植物养成
- **账本** - 财务管理
- **涂鸦** - 创意绘画
- **游戏房** - 休闲游戏
- **许愿柳** - 许愿功能
- **线下** - 线下活动

### 🎙️ 语音系统
- **语音通话** - 实时音频通话
- **视频通话** - WebRTC视频通话
- **语音合成** - MiniMax/小米MiMo/ElevenLabs
- **音色克隆** - 上传录音克隆专属音色
- **打字发语音** - 文字转语音

### 🎨 AI 生图
- 聊天中AI智能生图
- IG发帖AI配图
- 多种滤镜效果

### 🧠 智能记忆系统
- 分层记忆（核心/长期/短期/已淡化）
- 权重标记与标签分类
- 记忆关联网络
- AI整理记忆
- 会遗忘的拟真设计

### 🔔 推送通知
- 后台消息通知
- 角色主动发消息
- 可设置勿扰时段

## 技术特性

### 前端技术
- **PWA支持** - 可安装到桌面，离线使用
- **Service Worker** - 缓存策略优化
- **响应式设计** - 适配各种移动设备
- **多种聊天样式** - 正统美式/iMessage/微信

### 后端服务
- **Express.js** - Node.js后端框架
- **WebRTC信令** - 实时通信
- **音频转码** - ffmpeg处理
- **Supabase** - 数据库与认证
- **RAG检索** - 向量记忆检索

## 快速开始

### 方式一：纯前端预览

直接用浏览器打开 `index.html` 即可体验基本功能。

> 注意：`file:` 协议下不会注册 Service Worker 和 manifest

### 方式二：完整功能部署

需要 Node.js 16+ 环境：

```bash
# 安装依赖
npm install

# 启动服务
npm start
```

默认监听 `http://localhost:3000`，可通过环境变量 `PORT` 修改端口。

## 后端API接口

启动服务后可用的接口：

| 接口路径 | 功能说明 |
|---------|---------|
| `POST /api/convert-audio` | 视频抽音轨转换（克隆音色） |
| `POST/GET /api/webrtc/signal` | WebRTC信令中转 |
| `POST /api/imagegen` | AI生图代理 |
| `GET /api/weather?city=` | 天气查询 |
| `POST /api/rag/search` | RAG记忆检索 |
| `/relay` | 模型中继 |
| `/push/*` | 推送消息 |

## 配置说明

### 聊天设置
- **置顶聊天** - 优先显示
- **角色自主发动态** - IG首页自动发帖
- **对方输出语种** - 支持8种语言
- **显示翻译** - 回复下方显示中文
- **聊天模式** - 线下/异地切换
- **流式实时分条** - 边生成边弹出
- **回复分条数** - 自动/1-3条可选
- **主动消息** - 设置发送间隔和勿扰时段

### 语音设置
- **发音平台** - MiniMax/小米MiMo/ElevenLabs
- **音色选择** - 平台音色或自定义ID
- **声音风格** - 文字描述说话风格
- **音色克隆** - 上传10-30秒清晰录音

### 记忆设置
- **自动记录** - 对话后自动提取记忆
- **回顾条数** - 单次总结对话数量
- **总结间隔** - 多少轮自动总结

## 设计理念

### 聊天回复特色

1. **AI主动分段（多气泡）**
   - 角色将回复拆分为2-4条独立短消息
   - 条与条之间用 `‖` 分隔
   - 模拟真人发消息的节奏感

2. **流式实时分条**
   - SSE边接收边弹出气泡
   - 最像真人发短信的体验
   - 自动降级兼容不支持流式的接口

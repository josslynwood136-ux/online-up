# 美乐地（Mobile Web）

一个仿手机桌面的移动端网页 App：把多个「App」（打卡、IG、音乐、相册、恋爱日记、自习室……）放进一张全景壁纸里，核心是一个可与角色自由聊天的 AI 伴侣。纯静态前端，可直接用浏览器打开 `index.html`，也能作为 PWA 安装到手机桌面。

## 目录结构

```
index.html          入口页面（手机桌面 + 聊天窗 + 各 App 弹层）
css/style.css       样式
js/
  ui.js             通用 UI / 弹窗
  state.js          全局状态、设置默认值、Supabase/中继请求封装
  chat.js           聊天窗口 + AI 对话（核心）
  tts.js            语音合成（MiniMax / MiMo / ElevenLabs）
  apps.js           其它 App 与全局设置
  profile-ig.js     IG 资料 / 发帖
  push.js           系统推送通知
  init.js           初始化
  sync.js           角色/记忆同步
manifest.json / sw.js / icon*    PWA 资源
```

## 运行

- 直接用浏览器打开 `index.html` 即可（file: 协议下不会注册 Service Worker / manifest）。
- 要启用 PWA / 推送，需用 http(s) 托管（如任意静态服务器）。
- 在「设置」里填入 API 地址、Key、模型后即可聊天。

## 聊天回复的两个关键设计

1. **AI 主动分段（多气泡）**
   系统提示词要求角色把一次回复写成 2~4 条独立短消息，每条之间用分隔符 `‖` 隔开。前端 `splitReply()` 只按 `‖`（`|` / `｜` 也兼容）拆成多条气泡，AI 不分段就整段作为一条。这样回复像真人发短信一样一条条连着来，停顿与换话题的节奏完全由 AI 把控。

2. **流式实时分条（Streaming）**
   开启「流式实时分条」后，前端用 SSE 边接收边把已成型（`‖` 隔好）的段实时弹成气泡，打字指示器一直挂在最后，呈现「正在输入…→蹦出一句→还在输入→再蹦一句」的观感。
   - 设置位置：聊天设置 → 对话 → 流式实时分条（默认开）。
   - 接口不支持流式（或被中继代理缓冲）时，自动降级为「等整段返回再按 `‖` 拆」，不会空白或报错。

### 2026年8月25日 15:07（星期二）
- 聊天回复由「一次回复一条」改为「像真人短信一样连发多条」：
